## Shared blocks (reused in every listing)

### What's on the card
- **The cover:** one scene from the episode: the four friends at the table, a winner
  mid-celebration, Jojo hiding somewhere, and a few sparrows watching.
- **Meet the Sparrows:** the fold-in key showing which friend stands for which suit, so
  new players can read the card at a glance.
- **The hands:** [26/27] winning hands named for the episode. Each friend owns the same
  section on every card: Dottie the 2468 hands, Bea the 13579, Kiki the 369, Birdie the
  winds and dragons, Jojo the quints and Soap the singles and pairs.

[W × H in] folded.
